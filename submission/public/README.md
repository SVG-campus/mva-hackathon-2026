# Model 1 submission package

Publication-reviewed files prepared for the owner's final public-repository and live-submission gate:

- `svillalobos-gonzalez_model1_bub1b_predictions.csv` — one ranked compound-heterozygous BUB1B hypothesis.
- `svillalobos-gonzalez_model1_report.md` — methods, evidence, controls, resource receipt, and limitations.
- `candidate_evidence_bub1b.md` — bounded candidate-level evidence card with direct sources and falsifiers.
- `svillalobos-gonzalez_model1_methods.xlsx` — completed official Track 1 methods form.

The numeric EPCR is an uncalibrated ranking proxy. None of these files is a diagnosis, clinical validation, treatment recommendation, or estimate of personal outcome. No raw genomic file, clinical narrative, genome-scale table, or reconstructive intermediate is included.
